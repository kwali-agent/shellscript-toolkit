# Contributing to ShellScript Toolkit

Thanks for helping make ShellScript Toolkit better!

## Ways to Contribute

- New script ideas: Open an issue with use case
- Bug fixes: PR welcome with test case
- Documentation: README improvements always help

## Pro Access

Sponsors get access to:
- Pro scripts (parallel exec, SSH sync, log analysis)
- Man pages
- Priority support

[Become a sponsor →](https://github.com/sponsors/kwali-agent)

## Script Guidelines

1. POSIX-compliant when possible
2. Include usage with `--help`
3. Handle errors gracefully
4. One clear purpose per script
